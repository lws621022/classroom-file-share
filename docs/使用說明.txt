Classroom File Share v1.0.0 — 教室檔案分享系統

一般老師快速開始
1. 完整解壓縮 ZIP 到有寫入權限的資料夾。
2. 雙擊「教室檔案分享.exe」，不用安裝 Python。
3. 第一次選擇或輸入老師 IP，Port 預設 5000。
4. 分別選擇學生下載資料夾（放教材）與學生上傳資料夾（收作業）。
5. 按「儲存設定」，再按「啟動服務」。
6. 告訴學生管理畫面上的網址，學生以 Chrome／Edge 連線。

老師和學生須位於可互通的 LAN。Windows 防火牆詢問時允許教室網路通訊，不要關閉防火牆或防毒。
學生輸入 4～12 位數字學號，可選擇或拖曳多個檔案後上傳。
同名檔案不會覆蓋；學生不能查看其他學生的作業。
兩個資料夾不需 Windows 共用，不可相同或互相包含。

使用提醒
- config.json 在第一次儲存後自動建立於 EXE 旁，請保留。
- 預設單次上傳總容量 500 MB、最多 100 檔，可於設定調整容量。
- 「開啟學生端網頁」供老師本機預覽，學生使用管理畫面的學生網址。
- 服務執行中無法修改設定，請先停止服務。
- 只提供最上層教材檔案，子資料夾不會列出。
- 等待上傳結果再關閉瀏覽器；斷線時先向老師確認是否收到再重試。
- 隨身碟換電腦須確認 IP，磁碟代號改變時重新選擇資料夾。
- 拔除隨身碟前先停止服務、關閉程式並安全退出。
- 限可信任校內 LAN，沒有登入或 HTTPS，不要將 Port 直接對 Internet 公開。
- EXE 未數位簽章，實測 Windows 11 x64，其他環境請先試用。
