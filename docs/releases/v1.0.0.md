# Classroom File Share v1.0.0

第一個公開版本：適用於 Windows 電腦教室的 LAN 檔案分享工具。

## 本版功能

- 老師以 Windows GUI 啟動／停止服務，提供教材檔案下載。
- 學生免登入，透過瀏覽器輸入學號並上傳作業。
- 支援多檔選擇、拖曳上傳與進度／結果提示。
- 自動偵測老師 IPv4，可選擇網卡位址或手動修改。
- 支援中文檔名、空白與括號，同名上傳不覆蓋。
- 學生無法查看其他學生的上傳檔案。
- 不需要 Windows 共用資料夾、SMB、FTP、資料庫或雲端服務。
- 預設 Port 5000、單次總量 500 MB，可在設定視窗調整。

## 下載及開始使用

1. 下載 `ClassroomFileShare-v1.0.0-Windows.zip`，完整解壓縮。
2. 雙擊 `教室檔案分享.exe`，無需安裝 Python。
3. 設定老師 IP、Port、學生下載及上傳資料夾，按「儲存設定」。
4. 按「啟動服務」，將管理畫面顯示的網址告訴學生。
5. 學生於可互通的 LAN 使用 Chrome／Edge 開啟網址，例如 `http://192.168.1.100:5000`（虛構範例）。

Windows 防火牆詢問時允許教室使用的網路環境通訊，不需關閉防火牆或防毒。限可信任 LAN，請勿直接公開到 Internet。

## 版本與驗證

Windows x64 單檔成品，實測 Windows 11、Python 3.13.3 建置。11 組自動測試通過，先前亦實測成品首次設定、啟停、設定保留、瀏覽器中文下載與多檔上傳。

未驗證各教室跨機 LAN、無 Python 的乾淨電腦、500 MB 實際傳輸或整班長時間負載。拖曳已實作，瀏覽器實測使用檔案選擇器。EXE 未數位簽章。

隨身碟可攜帶程式與資料；設定使用絕對路徑，換電腦／磁碟代號後須確認 IP 和資料夾。
